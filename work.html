Projects

Showing all 6 projects

  • Campus Health Club page

    A responsive page for an online fitness club. I used semantic HTML, a shared color palette, and Flexbox to lay out the event cards.

    What I learned: a small set of consistent colors makes a page look planned.

    HTML CSS Flexbox

  • Recipe card grid

    A set of recipe cards that moves from one column on a phone to three on a desktop, using CSS Grid and one media query.

    What I learned: auto-fit columns can replace several media queries.

    CSS Grid Responsive

  • Accessibility audit

    I scanned a club page with WAVE and fixed missing alt text, unlabeled form fields, low contrast, an empty button, a missing language, a skipped heading, and vague link text.

    What I learned: most barriers come from small gaps in the HTML.

    WAVE Alt text Labels

  • Keyboard-friendly menu

    A navigation menu that works with only the Tab, Enter, and Escape keys, with a clear focus outline on every link.

    What I learned: a visible focus style helps every keyboard user.

    Keyboard Focus

  • Quiz timer

    A ten-question quiz with a countdown clock. JavaScript updates the score and moves to the next question without reloading the page.

    What I learned: small functions are easier to test than one long script.

    JavaScript DOM

  • Tip calculator

    A form that works out a tip and a split bill. It checks the numbers and shows a helpful message when something is missing.

    What I learned: a clear error message tells people how to fix the problem.

    JavaScript Forms
