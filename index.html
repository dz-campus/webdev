How I work

  • Start with the content

    I write the headings and text first, so the layout supports the message instead of hiding it.

  • Test with a keyboard

    If I cannot use a page with the Tab and Enter keys, I treat it as unfinished.

  • Check small and large

    I look at every page near 320 pixels wide and near 1200 pixels wide before I call it done.
